# Базар Учёт

Приложение для учёта выручки, закупок и прибыли за день.

## Вход

Теперь приложение закрыто логином и паролем. Без входа:

- главная страница перенаправляет на `/login`;
- API отчётов возвращает `401`.

Данные для входа хранятся в файле `.env` в папке проекта:

```env
APP_USERNAME=friend
APP_PASSWORD=ваш_пароль
SECRET_KEY=длинная_случайная_строка
COOKIE_SECURE=0
```

Пароль можно изменить в `.env` и перезапустить сервер.

### Несколько пользователей

Можно задать несколько логинов через `APP_USERS`:

```env
APP_USERS=owner:пароль1,friend:пароль2
```

Если задан `APP_USERS`, переменные `APP_USERNAME` и `APP_PASSWORD` не используются.

## Локальный запуск

```powershell
cd "C:\Users\Honor\Desktop\bazar app"
.\venv\Scripts\uvicorn.exe main:app --host 127.0.0.1 --port 8010
```

Открыть: `http://127.0.0.1:8010`

## Деплой на Render

В настройках сервиса добавьте переменные окружения:

- `MONGO_URL` — строка подключения к MongoDB;
- `APP_USERNAME` — логин;
- `APP_PASSWORD` — пароль;
- `SECRET_KEY` — длинная случайная строка;
- `COOKIE_SECURE=1` — для HTTPS.

После изменения переменных сделайте redeploy.

## Если нужно разлогинить всех

Измените `SECRET_KEY` — все старые cookie-сессии станут недействительными.
